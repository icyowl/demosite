『パターン認識と機械学習』の線形判別モデルを、Pythonで実装します。

I. 判別関数

  • 最小二乗法
  • フィッシャーの線形判別
  • パーセプトロン

II. サンプル

import matplotlib.pyplot as plt
import seaborn as sns
sns.set_theme()

df = sns.load_dataset('iris')
ax = sns.scatterplot(x=df.sepal_length, y=df.sepal_width, hue=df.species)

ax.set_title("Fisher's Iris")
plt.show()

III. 散布図
